# Power Platform App Doc Generator

This example demonstrates the core concept of a "Documentation Generator" for Power Platform applications. It takes a simplified Python dictionary representing an application's structure and components, then outputs a formatted Markdown document. This simulates how structured metadata can be transformed into comprehensive documentation.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal or command prompt in the same directory and run:
`python main.py`
